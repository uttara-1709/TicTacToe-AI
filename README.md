
# Unbeatable Tic-Tac-Toe AI

A mini-project implementing an AI opponent using Minimax and Alpha-Beta Pruning.

## Features
- Easy, Medium and Hard difficulty levels
- AI move selection using Minimax
- Alpha-Beta Pruning
- Score tracking
- Automated testing against a random opponent

## Technologies
- Python 3
- Tkinter
- Minimax Algorithm
- Alpha-Beta Pruning

## How to Run

Start the game:

```bash
python tic_tac_toe.py
```

Run the 10-game test:

```bash
python test_ai.py
```
